09 — Flow

Working Flow

What happens between a vehicle arriving and an operator guiding it to a slot, one cycle at a time.
STAGE 01
Detection

Slot occupancy state change is detected by the IR sensor and read by the ESP32.

STAGE 02
Processing

ESP32 packages the change into a JSON payload and prepares it for transmission.

STAGE 03
Backend Update

API persists the slot state to the database and broadcasts the updated record.

STAGE 04
Visualization

Dashboard refreshes the floor/slot grid in real time for security & administrative view.

STAGE 05
Guidance

Operator sees the vacant slot and directs the driver to it — closing the loop.

Continuous Monitoring Loop · Repeats every detection event
