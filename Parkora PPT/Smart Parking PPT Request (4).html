08 — Stack

Hardware & Software Stack

The prototype uses one sensor family, one MCU class, lightweight dashboard, and a single MQTT broker.
Hardware
Embedded
ESP32
Primary microcontroller with Wi-Fi for sensor data acquisition at each slot.
IR Sensor
Vehicle presence detection at each parking slot — binary occupied / vacant output.
LED Indicators
Local slot-level feedback — green for available, red for occupied.
Power Unit
Regulated 5V / 3.3V distribution for stable MCU and sensor operation.
Software
Full-Stack
React
Single Page Application for the real-time security dashboard.
Node.js
Centralized API server for MQTT message ingest and event processing.
PostgreSQL
Relational store for slot metadata, occupancy history, audit events.
MQTT
Lightweight pub/sub protocol for IoT sensor-to-server messaging.
IR sensor chosen for binary detection · directly compatible with ESP32 3.3V GPIO · HC-SR04 not used (5V echo level incompatible without shifting)
